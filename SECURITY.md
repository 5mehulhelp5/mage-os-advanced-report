# Security policy

## Supported versions

Security fixes are provided for the latest stable tagged release, starting with 1.0.0. Install the latest available patch release in that line.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository so maintainers can investigate and coordinate a fix before disclosure.

Include the affected version or commit, reproduction steps, expected impact, and any suggested mitigation. We will acknowledge a complete report as soon as maintainers are available and will keep the reporter informed while the issue is assessed.
